TuSalud+ · Sitio web corporativo y landing pages (prueba piloto)
================================================================

ESTRUCTURA
----------
tusalud_web/
  index.html          Inicio: elige perfil (Paciente / Cuidador)
  nosotros.html       Quiénes somos, misión, visión, valores, historia
  servicios.html      Funciones y planes
  preguntas.html      Preguntas frecuentes (app + prueba piloto)
  experiencia.html    Invitación a la prueba (testimonios: después del piloto)
  prensa.html         Logo, colores, mapa del sitio, redes
  contacto.html       Datos y formulario de contacto
  politicas.html      Términos, datos personales, devoluciones
  paciente/index.html Landing page PACIENTE (trato de "usted", letra grande)
  cuidador/index.html Landing page CUIDADOR (trato de "tú")
  assets/css/estilos.css   Estilos de todo el sitio (colores en :root)
  assets/js/main.js        Menú en celular + envío de formularios
  assets/img/logo.png      Logo

VER EL SITIO EN EL COMPUTADOR
-----------------------------
Doble clic en index.html.

FORMULARIOS
-----------
Llegan al correo tusaludmas8@gmail.com mediante FormSubmit (gratis).
La PRIMERA vez que alguien envíe un formulario (con el sitio ya publicado),
llega un correo de "Activate form" a esa cuenta: hay que abrirlo y confirmar.
Después de eso, cada inscripción llega como un correo con una tabla de datos.
Para cambiar el correo: editar CORREO_DESTINO en assets/js/main.js.

Para actualizar el sitio después de cambiar archivos (en esta carpeta):
  git add -A
  git commit -m "Describir el cambio"
  git push
GitHub vuelve a publicarlo solo en 1-2 minutos.
También se puede editar un archivo directamente en github.com (ícono del lápiz)
y guardar con "Commit changes".

Para que otros integrantes del equipo puedan subir cambios:
  Repositorio -> Settings -> Collaborators -> Add people.

VER EL SITIO EN EL COMPUTADOR
-----------------------------
Doble clic en index.html.

FORMULARIOS
-----------
Llegan al correo tusaludmas8@gmail.com mediante FormSubmit (gratis).
La PRIMERA vez que alguien envíe un formulario (con el sitio ya publicado),
llega un correo de "Activate form" a esa cuenta: hay que abrirlo y confirmar.
Después de eso, cada inscripción llega como un correo con una tabla de datos.
Para cambiar el correo: editar CORREO_DESTINO en assets/js/main.js.

PUBLICARLO EN INTERNET (gratis)
-------------------------------
Opción rápida - Netlify Drop:
  1. Entrar a https://app.netlify.com/drop
  2. Arrastrar la carpeta tusalud_web completa.
  3. Crear cuenta para que el enlace no expire y cambiar el nombre del sitio
     (ej. tusalud-mas.netlify.app).
  Para actualizar: en el sitio de Netlify -> Deploys -> arrastrar la carpeta otra vez.

Opción GitHub Pages:
  1. Crear un repositorio (ej. tusalud_web) y subir el CONTENIDO de esta carpeta.
  2. Settings -> Pages -> Branch: main / root -> Save.

Enlaces para compartir (ejemplo con Netlify):
  Sitio corporativo:   https://tusalud-mas.netlify.app/
  Landing paciente:    https://tusalud-mas.netlify.app/paciente/
  Landing cuidador:    https://tusalud-mas.netlify.app/cuidador/
